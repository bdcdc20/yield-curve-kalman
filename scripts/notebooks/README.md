# Notebook generators

Notebooks 03–11 are generated by these scripts, then executed. Notebooks 01
and 02 were written as notebooks and are their own source.

```bash
# from the repository root
python scripts/notebooks/make_nb07.py
jupyter nbconvert --to notebook --execute --inplace notebooks/07_shadow_rate.ipynb
```

- Each `make_nbXX.py` writes `notebooks/XX_*.ipynb`, with code and text cells
  only. Executing it fills in the outputs from `data/` and `data/results/`,
  and runs the backtests first through `ensure_results` if they are missing.
- The **takeaways** (the last section of notebooks 05–11) are in
  `takeaways/nbXX.md`. They were written after reading the executed outputs,
  and every number in them was checked against those outputs. If the data or
  models change, re-run the notebook and update its takeaways to match before
  committing.
- `python -m yck figures` rebuilds the README figures in `docs/figures/`.
